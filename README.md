Power Quality Disturbance Classification Using Statistical Features and Machine Learning
This is a project title related to Electrical Engineering, Power Systems, and Machine Learning.

The idea is to develop a machine learning model that can identify different types of power quality disturbances in an electrical power system by analyzing voltage or current signals.
=======
# Power-Quality-Disturbance-Classification-Using-Statistical-Features-and-Machine-Learning
This project develops an automated system to classify Power Quality Disturbances (PQDs) using statistical features and machine learning. By extracting metrics like skewness and variance from grid signals, it trains classifiers to detect sags, swells, and harmonics, ensuring grid stability.
